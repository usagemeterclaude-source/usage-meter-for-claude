Claude Code usage limits explained: what counts, how to check and how to save

Short answer: with a Pro, Max or Ultra plan, Claude Code has no separate quota – it uses the same 5-hour session and weekly limits as claude.ai and Claude Desktop. Run /usage in Claude Code to see your plan usage and what is using it. Long sessions, big context, subagents and MCP servers use the limit fastest; /clear, a lighter model and specific prompts save the most.

Claude Code shares your plan's limits

When you sign in to Claude Code with your claude.ai subscription, all activity in Claude Code, the claude.ai chat, Claude Desktop and the IDE extensions (VS Code, JetBrains) counts against one shared set of limits:

PlanLimits that apply to Claude Code
Pro5-hour session limit + weekly limit
Max5× Pro, every 5 hours and every week; plus a separate weekly limit for the largest model
Ultra10× Pro every week; verified accounts have no 5-hour limit; separate weekly limit for the largest model

So a morning of heavy coding can leave little for chatting in the afternoon – and the other way round. For a full comparison of the plans see Claude Pro vs Max vs Ultra.

Careful with API keys: if the ANTHROPIC_API_KEY environment variable is set, Claude Code uses that key instead of your subscription – and you pay API prices for every request.

How to check your Claude Code usage

  • /usage – shows your plan usage bars and a breakdown of what is using them: skills, subagents, plugins and individual MCP servers, with recommendations such as trimming a large CLAUDE.md. Press d / w to switch between the last 24 hours and 7 days.
  • Settings → Usage on claude.ai – the authoritative view of your session and weekly limits, including usage from other computers, the chat and your phone. The /usage breakdown only uses the local session history of the machine you're on.
  • /context – shows what is currently taking up space in the context window.

Why Claude Code uses your limit so fast

  • The whole conversation is sent with every request – and every tool call (reading a file, running tests) is another request carrying that context. A one-line question in a session that has been open all day still costs the whole history.
  • Coming back after a break – your first message after the prompt cache expires reprocesses the full context.
  • Subagents and agent teams – each one sends its own requests on top of your main session.
  • Background work – scheduled tasks and loops keep running while you're away.
  • Large CLAUDE.md and many MCP servers – loaded into context with every session.
  • The largest model and high effort – thinking tokens count as output.

How to make your limit last longer

  1. /clear between unrelated tasks. Stale context is resent with every message. Use /rename first if you want to /resume the session later.
  2. /compact for long tasks you want to continue – it summarises the conversation (it is itself a large request, so don't run it every few minutes).
  3. Pick the model for the job with /model, and lower /effort for simple work.
  4. Trim your setup: keep CLAUDE.md short (move specialised instructions into skills) and disable MCP servers you don't use with /mcp.
  5. Write specific prompts – "add input validation to the login function in auth.ts" instead of "improve this codebase".
  6. Use plan mode (Shift+Tab) for bigger changes and press Esc early if Claude heads the wrong way.
  7. Close sessions and stop loops you no longer need.

More causes and fixes – also for the claude.ai chat – are in Why do I hit the Claude usage limit so fast?

When you hit the limit in Claude Code

  • Claude Code tells you whether you hit the session or the weekly limit and when it resets. Switching models doesn't help for these – they apply across all models (it only helps with a model-specific weekly limit).
  • If the 5-hour limit is reached in the middle of a response, Claude Code may finish it with a small, capped allowance ("wrapping up").
  • With usage credits turned on (/usage-credits), you can keep working and pay for the extra usage, up to a monthly cap you set.
  • Otherwise, wait for the reset – Claude Code can also wait and continue the interrupted task automatically.

Frequently asked questions

Does Claude Code have its own usage limit?

No. With a Pro, Max or Ultra subscription, Claude Code shares the same 5-hour session and weekly limits as claude.ai and Claude Desktop.

How do I check my usage in Claude Code?

Run /usage. It shows your plan usage and what is using it. For usage across all your devices, check Settings → Usage on claude.ai.

Why does Claude Code use up my limit so quickly?

Every request carries the whole conversation plus tool results, and subagents, MCP servers and long sessions add more. Clearing context between tasks and using lighter models helps the most.

Does switching models help when I hit the limit?

Not for the session or weekly limit, which apply across all models. It only helps if you hit a model-specific weekly limit.

Can I keep working after hitting the limit?

Yes, if usage credits are turned on for your paid plan – you pay for the extra usage up to a monthly cap you set. Otherwise you wait for the reset.
