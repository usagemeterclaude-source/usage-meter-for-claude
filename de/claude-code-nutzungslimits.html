Claude-Code-Nutzungslimits erklärt: Was zählt, wie Sie sie prüfen und wie Sie sparen

Aktualisiert am 20. November 2026 · 6 Min. Lesezeit

EnglishSlovenčinaČeštinaDeutschItalianoFrançais
Kurz gesagt: Mit einem Pro-, Max- oder Ultra-Tarif hat Claude Code kein eigenes Kontingent – es nutzt dieselben 5-Stunden-Sitzungs- und Wochenlimits wie claude.ai und Claude Desktop. Führen Sie in Claude Code /usage aus, um Ihren Tarifverbrauch zu sehen und was ihn verursacht. Lange Sitzungen, großer Kontext, Subagenten und MCP-Server verbrauchen das Limit am schnellsten; /clear, ein leichteres Modell und konkrete Prompts sparen am meisten.

Claude Code teilt sich die Limits Ihres Tarifs

Wenn Sie sich in Claude Code mit Ihrem claude.ai-Abo anmelden, zählt alles, was Sie in Claude Code, im Chat auf claude.ai, in Claude Desktop und in den IDE-Erweiterungen (VS Code, JetBrains) tun, auf ein gemeinsames Kontingent:

TarifLimits, die für Claude Code gelten
Pro5-Stunden-Sitzungslimit + Wochenlimit
Max5× Pro, alle 5 Stunden und jede Woche; dazu ein separates Wochenlimit für das größte Modell
Ultra10× Pro pro Woche; verifizierte Konten haben kein 5-Stunden-Limit; separates Wochenlimit für das größte Modell

Ein Vormittag mit intensivem Programmieren kann also am Nachmittag kaum noch etwas fürs Chatten übrig lassen – und umgekehrt. Einen vollständigen Vergleich der Tarife finden Sie unter Claude Pro vs. Max vs. Ultra.

Vorsicht bei API-Schlüsseln: Ist die Umgebungsvariable ANTHROPIC_API_KEY gesetzt, verwendet Claude Code diesen Schlüssel statt Ihres Abos – und Sie zahlen für jede Anfrage API-Preise.

So prüfen Sie Ihren Verbrauch in Claude Code

  • /usage – zeigt die Verbrauchsbalken Ihres Tarifs und eine Aufschlüsselung, was sie belegt: Skills, Subagenten, Plugins und einzelne MCP-Server, dazu Empfehlungen wie das Kürzen einer großen CLAUDE.md. Mit d / w wechseln Sie zwischen den letzten 24 Stunden und 7 Tagen.
  • Settings → Usage (Einstellungen → Nutzung) auf claude.ai – die maßgebliche Ansicht Ihrer Sitzungs- und Wochenlimits, einschließlich der Nutzung auf anderen Computern, im Chat und auf Ihrem Smartphone. Die Aufschlüsselung in /usage stützt sich nur auf den lokalen Sitzungsverlauf des Rechners, an dem Sie gerade arbeiten.
  • /context – zeigt, was das Kontextfenster gerade belegt.

Warum Claude Code Ihr Limit so schnell verbraucht

  • Mit jeder Anfrage wird die gesamte Unterhaltung gesendet – und jeder Tool-Aufruf (eine Datei lesen, Tests ausführen) ist eine weitere Anfrage mit diesem Kontext. Eine einzeilige Frage in einer Sitzung, die den ganzen Tag offen war, kostet trotzdem den gesamten Verlauf.
  • Rückkehr nach einer Pause – Ihre erste Nachricht nach Ablauf des Prompt-Caches verarbeitet den gesamten Kontext neu.
  • Subagenten und Agenten-Teams – jeder sendet eigene Anfragen zusätzlich zu Ihrer Hauptsitzung.
  • Arbeit im Hintergrund – geplante Aufgaben und Schleifen laufen weiter, während Sie nicht da sind.
  • Große CLAUDE.md und viele MCP-Server – werden in jeder Sitzung in den Kontext geladen.
  • Das größte Modell und hohe Effort-Stufe – Denk-Tokens zählen als Ausgabe.

So reicht Ihr Limit länger

  1. /clear zwischen Aufgaben, die nichts miteinander zu tun haben. Veralteter Kontext wird sonst mit jeder Nachricht erneut gesendet. Nutzen Sie vorher /rename, wenn Sie die Sitzung später mit /resume fortsetzen möchten.
  2. /compact für lange Aufgaben, die Sie fortsetzen möchten – fasst die Unterhaltung zusammen (das ist selbst eine große Anfrage, also nicht alle paar Minuten ausführen).
  3. Wählen Sie das passende Modell mit /model und senken Sie /effort bei einfachen Aufgaben.
  4. Schlanke Einrichtung: Halten Sie CLAUDE.md kurz (spezielle Anweisungen gehören in Skills) und deaktivieren Sie nicht genutzte MCP-Server mit /mcp.
  5. Schreiben Sie konkrete Prompts – „füge der Login-Funktion in auth.ts eine Eingabevalidierung hinzu“ statt „verbessere diese Codebasis“.
  6. Nutzen Sie den Plan-Modus (Shift+Tab) für größere Änderungen und drücken Sie früh Esc, wenn Claude in die falsche Richtung läuft.
  7. Schließen Sie Sitzungen und beenden Sie Schleifen, die Sie nicht mehr brauchen.

Weitere Ursachen und Lösungen – auch für den Chat auf claude.ai – finden Sie unter Warum ist das Claude-Limit so schnell erreicht?

Wenn Sie in Claude Code das Limit erreichen

  • Claude Code teilt Ihnen mit, ob Sie das Sitzungs- oder das Wochenlimit erreicht haben und wann es zurückgesetzt wird. Ein Modellwechsel hilft hier nicht – diese Limits gelten modellübergreifend (er hilft nur bei einem modellspezifischen Wochenlimit).
  • Wird das 5-Stunden-Limit mitten in einer Antwort erreicht, kann Claude Code sie mit einem kleinen, begrenzten Restkontingent noch zu Ende bringen („wrapping up“).
  • Mit aktiviertem Nutzungsguthaben (/usage-credits) können Sie weiterarbeiten und zahlen für die zusätzliche Nutzung, bis zu einer selbst festgelegten monatlichen Obergrenze.
  • Andernfalls warten Sie auf das Zurücksetzen – Claude Code kann auch warten und die unterbrochene Aufgabe danach automatisch fortsetzen.

Sehen Sie Ihr Limit, bevor Sie eine große Aufgabe starten

Usage Meter for Claude ist eine kostenlose Browser-Erweiterung, die Ihren Claude-Verbrauch auf dem Symbol in der Symbolleiste anzeigt – einschließlich der Nutzung über Claude Code. Das Popup zeigt Ihre Sitzungs- und Wochenlimits samt Zeitpunkt des Zurücksetzens und eine Prognose, wann Sie beim aktuellen Tempo das Limit erreichen, und eine Benachrichtigung warnt Sie, bevor es so weit ist. Ideal, um zu entscheiden, ob Sie das Refactoring jetzt starten oder erst nach dem Zurücksetzen.

Häufige Fragen

Hat Claude Code ein eigenes Nutzungslimit?

Nein. Mit einem Pro-, Max- oder Ultra-Abo teilt sich Claude Code dieselben 5-Stunden-Sitzungs- und Wochenlimits wie claude.ai und Claude Desktop.

Wie prüfe ich meinen Verbrauch in Claude Code?

Führen Sie /usage aus. Der Befehl zeigt Ihren Tarifverbrauch und was ihn verursacht. Den Verbrauch über alle Ihre Geräte sehen Sie unter Settings → Usage auf claude.ai.

Warum verbraucht Claude Code mein Limit so schnell?

Jede Anfrage enthält die gesamte Unterhaltung samt Tool-Ergebnissen, und Subagenten, MCP-Server und lange Sitzungen kommen noch hinzu. Am meisten hilft es, den Kontext zwischen Aufgaben zu leeren und leichtere Modelle zu nutzen.

Hilft der Wechsel zu einem anderen Modell, wenn ich das Limit erreicht habe?

Nicht beim Sitzungs- oder Wochenlimit – diese gelten modellübergreifend. Es hilft nur, wenn Sie ein modellspezifisches Wochenlimit erreicht haben.

Kann ich nach Erreichen des Limits weiterarbeiten?

Ja, wenn in Ihrem kostenpflichtigen Tarif das Nutzungsguthaben aktiviert ist – Sie zahlen für die zusätzliche Nutzung bis zu einer selbst festgelegten monatlichen Obergrenze. Andernfalls warten Sie auf das Zurücksetzen.
