Wann wird das Claude-Limit zurückgesetzt?

Aktualisiert am 24. November 2026 · 5 Min. Lesezeit

EnglishSlovenčinaČeštinaDeutschItalianoFrançais
Kurz gesagt: Das 5-Stunden-Sitzungslimit wird fünf Stunden nach Ihrer ersten Nachricht in dieser Sitzung zurückgesetzt. Das Wochenlimit wird an einem festen Tag zu einer festen Uhrzeit zurückgesetzt, die Ihrem Konto zugewiesen sind – jede Woche gleich, egal wann Sie mit Claude angefangen haben. Beide genauen Zeitpunkte sehen Sie unter Settings → Usage auf claude.ai.

Zwei Uhren: Sitzung und Woche

Die Tarife Claude Pro, Max und Ultra haben zwei Limits, die parallel laufen, und jedes wird für sich zurückgesetzt:

LimitWann es zurückgesetzt wird
5-Stunden-SitzungslimitFünf Stunden nach der ersten Nachricht der Sitzung, vollständig
Wochenlimit (alle Modelle)Einmal pro Woche, an einem festen Tag zu einer festen Uhrzeit, die Ihrem Konto zugewiesen sind
Wochenlimit für das größte Modell (Max, Ultra)Einmal pro Woche – unter Settings → Usage separat angezeigt

Erreichen Sie eines davon, geht es erst nach dem Zurücksetzen weiter. Deshalb können Sie gesperrt sein, obwohl von der Sitzung noch reichlich übrig ist – dann wurde zuerst das Wochenlimit erreicht. Verifizierte Ultra-Konten haben kein 5-Stunden-Limit, nur die Wochenlimits. Mehr zu den Tarifen unter Claude Pro vs. Max vs. Ultra.

So funktioniert die 5-Stunden-Sitzung

Die Sitzung ist kein gleitendes Zeitfenster. Sie beginnt mit Ihrer ersten Nachricht, und fünf Stunden später steht das ganze Limit wieder zur Verfügung. Senden Sie nach dem Zurücksetzen eine Weile nichts, beginnt die nächste Sitzung erst mit Ihrer nächsten Nachricht.

Beispiel: Ihre erste Nachricht senden Sie um 9:10 Uhr. Alles, was Sie bis 14:10 Uhr nutzen, zählt zu dieser Sitzung. Um 14:10 Uhr wird das Sitzungslimit zurückgesetzt – und mit der nächsten Nachricht beginnt eine neue Sitzung.

Tipp: Wenn Sie wissen, dass Sie am Nachmittag einen langen Arbeitsblock brauchen, startet eine kurze Nachricht ein paar Stunden vorher die Uhr – so steht eine frische Sitzung früher bereit.

Auch der Free-Tarif hat ein sitzungsbasiertes Limit, das alle fünf Stunden zurückgesetzt wird.

So funktioniert das wöchentliche Zurücksetzen

Das Wochenlimit zählt nicht sieben Tage ab Ihrer ersten Nachricht. Es wird jede Woche zu einem festen Zeitpunkt zurückgesetzt, der Ihrem Konto zugewiesen ist, und dieser Tag und diese Uhrzeit bleiben gleich, unabhängig davon, wann Ihr Abo begonnen hat. Zwei Personen mit demselben Tarif können daher unterschiedliche Tage für das Zurücksetzen haben.

Weil sich das wöchentliche Zurücksetzen nicht verschiebt, lohnt es sich zu wissen, wie viel von der Woche noch übrig ist: 60 % Verbrauch am 2. Tag sind etwas ganz anderes als 60 % am 6. Tag.

Wo Sie den genauen Zeitpunkt sehen

  • claude.ai → Settings → Usage – „Current session“ zeigt, wie viel verbraucht ist und wie lange es bis zum Zurücksetzen dauert; „Weekly limits“ zeigt, wann das Wochenlimit zurückgesetzt wird, für alle Modelle und für das größte Modell, falls Ihr Tarif dafür ein separates Limit hat.
  • Claude Code – wenn Sie ein Limit erreichen, sagt Ihnen die Meldung, ob es das Sitzungs- oder das Wochenlimit war und wann es zurückgesetzt wird. /usage zeigt Ihren Tarifverbrauch. Mehr dazu unter Claude-Code-Nutzungslimits erklärt.
  • In der Symbolleiste Ihres Browsers – die kostenlose Erweiterung Usage Meter for Claude zeigt die Zeitpunkte des Zurücksetzens jederzeit an, ohne dass Sie die Einstellungen öffnen müssen.

Claude Code, die Desktop-App, das Smartphone und der Chat teilen sich dieselben Limits – und damit auch dieselben Zeitpunkte des Zurücksetzens.

Lässt sich das Limit vorzeitig zurücksetzen?

  • Limit-Resets: Anthropic gewährt berechtigten Tarifen gelegentlich ein kostenloses Limit-Reset – für das 5-Stunden-Limit, das Wochenlimit oder das Limit für das größte Modell. Wenn Sie eines haben, finden Sie es unter Settings → Usage → Limit resets („Reset for free“). Sie können es nutzen, bevor Sie das Limit erreichen, aber ein ungenutztes Reset verfällt zum angezeigten Datum, und in Claude Code im Terminal steht es nicht zur Verfügung. Ihr reguläres wöchentliches Zurücksetzen bleibt am gewohnten Tag zur gewohnten Uhrzeit.
  • Nutzungsguthaben und Pakete: Mit aktiviertem Nutzungsguthaben können Sie nach Erreichen eines Limits zu nutzungsabhängigen Preisen weiterarbeiten, bis zu der monatlichen Obergrenze, die Sie festgelegt haben. Das Limit wird dadurch nicht zurückgesetzt, und der Zeitpunkt des Zurücksetzens ändert sich nicht.
  • Upgrade: Die Limits eines höheren Tarifs gelten sofort, ein Zurücksetzen ist das aber nicht.

Ansonsten warten Sie auf das Zurücksetzen. Währenddessen hilft es zu wissen, warum das Limit so schnell erreicht ist – damit die nächste Sitzung länger reicht.

Zeitpunkte des Zurücksetzens auf einen Blick

Usage Meter for Claude ist eine kostenlose Browser-Erweiterung, die Ihren Claude-Verbrauch auf dem Symbol in der Symbolleiste anzeigt. Das Popup zeigt, wann Ihre Sitzungs- und Wochenlimits zurückgesetzt werden, und prognostiziert, wann Sie beim aktuellen Tempo das Limit erreichen. Sie erhalten eine Benachrichtigung, wenn ein Limit zurückgesetzt wird – und bevor ein kostenloses Limit-Reset verfällt, damit Sie es nicht verschenken.

Häufige Fragen

Wann wird das 5-Stunden-Limit von Claude zurückgesetzt?

Fünf Stunden nach der ersten Nachricht der Sitzung. Das Zeitfenster beginnt mit Ihrer ersten Nachricht und wird danach vollständig zurückgesetzt – es ist kein gleitendes Fenster.

Wann wird das Wochenlimit von Claude zurückgesetzt?

Jede Woche an einem festen Tag zu einer festen Uhrzeit, die Ihrem Konto zugewiesen sind. Das hängt weder davon ab, wann Sie Claude zu nutzen beginnen, noch davon, wann Ihr Abo begonnen hat. Den genauen Zeitpunkt sehen Sie unter Settings → Usage auf claude.ai.

Kann ich mein Claude-Limit vorzeitig zurücksetzen?

Nur wenn Anthropic Ihrem Konto ein Limit-Reset gewährt hat – dann können Sie es unter Settings → Usage mit „Reset for free“ nutzen, bevor es verfällt. Mit Nutzungsguthaben und Paketen können Sie weiterarbeiten, der Zeitpunkt des Zurücksetzens verschiebt sich dadurch aber nicht.

Hat Claude Code einen anderen Zeitpunkt für das Zurücksetzen?

Nein. Mit einem Pro-, Max- oder Ultra-Tarif teilt sich Claude Code dieselben Sitzungs- und Wochenlimits wie claude.ai und Claude Desktop, daher sind auch die Zeitpunkte des Zurücksetzens dieselben.

Setzt ein Tarif-Upgrade das Limit zurück?

Ein Zurücksetzen im eigentlichen Sinn ist es nicht, aber die höheren Limits des neuen Tarifs gelten sofort.
