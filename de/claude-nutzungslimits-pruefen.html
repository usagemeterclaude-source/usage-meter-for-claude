Kurz gesagt: Öffnen Sie auf claude.ai Settings → Usage (Einstellungen → Nutzung). Dort sehen Sie Ihr 5-Stunden-Sitzungslimit und Ihre Wochenlimits als Fortschrittsbalken, jeweils mit dem nächsten Zeitpunkt des Zurücksetzens. In Claude Code führen Sie /usage aus. claude.ai, Claude Code und Claude Desktop zählen alle auf dieselben Limits.

1. Limits auf claude.ai prüfen

  1. Öffnen Sie claude.ai und melden Sie sich an.
  2. Klicken Sie unten links auf Ihren Namen oder Ihre Initialen und wählen Sie Settings.
  3. Öffnen Sie den Tab Usage.

Die Seite Usage ist in den Tarifen Pro, Max, Ultra, Team und im platzbasierten Enterprise-Tarif verfügbar. Sie zeigt:

Was Sie sehenWas es bedeutet
Aktuelle SitzungWie viel Sie von Ihrem 5-Stunden-Sitzungslimit verbraucht haben und wann es zurückgesetzt wird.
Wöchentlich – alle ModelleIhr modellübergreifendes Wochenlimit und der Zeitpunkt, zu dem es zurückgesetzt wird.
Wöchentlich – ein bestimmtes ModellIn manchen Tarifen gibt es ein separates Wochenlimit für das größte Modell.
NutzungsguthabenFalls aktiviert: wie viel Sie über Ihren Tarif hinaus ausgegeben haben und Ihre monatliche Obergrenze.

2. Limits in Claude Code prüfen

Wenn Sie Claude Code mit Ihrem claude.ai-Abonnement nutzen, geben Sie in einer Sitzung /usage ein. Sie erhalten eine Aufschlüsselung Ihrer Tarifnutzung samt Vorschlägen, wie Sie Ihr Kontingent effizienter einsetzen.

Beachten Sie, dass /usage auf Ihrem lokalen Sitzungsverlauf basiert – Nutzung auf anderen Computern, auf claude.ai oder auf Ihrem Smartphone ist dort nicht enthalten. Das vollständige Bild liefert Settings → Usage auf claude.ai. Nutzungsguthaben verwalten Sie in Claude Code mit /usage-credits.

3. So funktionieren die Claude-Limits

Das 5-Stunden-Sitzungslimit

In kostenpflichtigen Tarifen beginnt eine Sitzung mit Ihrer ersten Nachricht und wird fünf Stunden später vollständig zurückgesetzt. Beginnen Sie um 9:00 Uhr, wird Ihre Sitzung um 14:00 Uhr zurückgesetzt – egal, wie viel Sie dazwischen verbraucht haben.

Die Wochenlimits

Wochenlimits werden zu einem festen Zeitpunkt jede Woche zurückgesetzt, der Ihrem Konto zugewiesen ist – nicht für alle am Montag. Den genauen Tag und die Uhrzeit finden Sie unter Settings → Usage.

Ein gemeinsames Kontingent

Chatten auf claude.ai, Programmieren mit Claude Code und die Nutzung von Claude Desktop zehren alle von denselben Limits. Eine lange Claude-Code-Sitzung am Vormittag kann am Nachmittag weniger fürs Chatten übrig lassen. Anthropic kann die Limits zudem im Lauf der Zeit anpassen, um die Kapazität zu steuern – wie viel Arbeit genau in eine Sitzung passt, kann sich also ändern.

4. Was tun, wenn das Limit erreicht ist?

  • Auf das Zurücksetzen warten. Unter Settings → Usage sehen Sie genau, wann Ihre Sitzung oder Woche zurückgesetzt wird.
  • Nutzungsguthaben verwenden. In kostenpflichtigen Tarifen mit aktiviertem Nutzungsguthaben können Sie weiterarbeiten und für die zusätzliche Nutzung bezahlen.
  • Eine neue Unterhaltung beginnen, wenn Sie das Thema wechseln. Lange Unterhaltungen verbrauchen mit jeder Nachricht mehr von Ihrem Limit, weil Claude den gesamten Kontext erneut liest.
  • Ein leichteres Modell nutzen für einfache Aufgaben und das größte Modell für die schwierigen aufheben.
  • Aufwendige Arbeit planen – prüfen Sie, wie viel von Ihrer Sitzung noch übrig ist, bevor Sie eine große Claude-Code-Aufgabe starten.

Ihre Limits sehen, ohne die Einstellungen zu öffnen

Usage Meter for Claude ist eine kostenlose Browser-Erweiterung, die Ihre Claude-Nutzung stets im Blick behält: Der Prozentwert steht auf dem Symbol in der Symbolleiste, das Popup zeigt Ihre Sitzungs- und Wochenlimits samt Zeitpunkt des Zurücksetzens, eine Prognose verrät, wann Sie beim aktuellen Tempo das Limit erreichen, und eine Benachrichtigung warnt Sie, bevor es so weit ist. Häufige Fragen

Wo sehe ich meine Claude-Nutzungslimits?

Auf claude.ai unter Settings → Usage – verfügbar in den Tarifen Pro, Max, Ultra, Team und im platzbasierten Enterprise-Tarif.

Wann wird das 5-Stunden-Sitzungslimit zurückgesetzt?

Fünf Stunden nach der ersten Nachricht der Sitzung.

Wann werden die Wochenlimits zurückgesetzt?

Jede Woche zu einem festen, Ihrem Konto zugewiesenen Zeitpunkt – Ihren finden Sie unter Settings → Usage.

Hat Claude Code eigene Limits?

Nein. Claude Code, claude.ai und Claude Desktop teilen sich dieselben Limits. /usage in Claude Code zeigt nur die Nutzung aus Ihren lokalen Sitzungen.

Kann ich die Nutzung im kostenlosen Tarif sehen?

Auch der kostenlose Tarif hat Limits, aber die Seite Usage mit den Balken für Sitzung und Woche gehört zu den kostenpflichtigen Tarifen.
