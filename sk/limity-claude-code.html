Limity Claude Code v kocke: čo sa počíta, ako ich zistiť a ako ušetriť

Aktualizované 20. novembra 2026 · 6 min čítania

EnglishSlovenčinaČeštinaDeutschItalianoFrançais
Stručne: s plánom Pro, Max alebo Ultra nemá Claude Code žiadnu samostatnú kvótu – čerpá z toho istého 5-hodinového limitu relácie aj týždenného limitu ako claude.ai a Claude Desktop. Spustite v Claude Code /usage a uvidíte spotrebu svojho plánu aj to, čo ju míňa. Najrýchlejšie limit minú dlhé relácie, veľký kontext, subagenti a servery MCP; najviac ušetríte cez /clear, ľahší model a konkrétne zadania.

Claude Code zdieľa limity vášho plánu

Keď sa do Claude Code prihlásite predplatným z claude.ai, všetka aktivita v Claude Code, v chate na claude.ai, v Claude Desktop aj v rozšíreniach pre IDE (VS Code, JetBrains) sa započítava do jednej spoločnej sady limitov:

PlánLimity, ktoré platia pre Claude Code
Pro5-hodinový limit relácie + týždenný limit
Max5× Pro, každých 5 hodín aj každý týždeň; navyše samostatný týždenný limit pre najväčší model
Ultra10× Pro každý týždeň; overené účty nemajú 5-hodinový limit; samostatný týždenný limit pre najväčší model

Dopoludnie intenzívneho programovania vám teda môže nechať na popoludňajšie chatovanie len málo – a platí to aj naopak. Úplné porovnanie plánov nájdete v článku Claude Pro vs Max vs Ultra.

Pozor na API kľúče: ak máte nastavenú premennú prostredia ANTHROPIC_API_KEY, Claude Code použije namiesto predplatného tento kľúč – a za každú požiadavku platíte ceny API.

Ako zistiť svoju spotrebu v Claude Code

  • /usage – ukáže pruhy spotreby vášho plánu a rozpis toho, čo ju míňa: skills, subagenti, pluginy a jednotlivé servery MCP, s odporúčaniami, napríklad skrátiť veľký CLAUDE.md. Klávesmi d / w prepínate medzi poslednými 24 hodinami a 7 dňami.
  • Settings → Usage (Nastavenia → Využitie) na claude.ai – smerodajný prehľad limitu relácie aj týždenného limitu vrátane spotreby z iných počítačov, z chatu aj z telefónu. Rozpis v /usage vychádza len z lokálnej histórie relácií na počítači, na ktorom práve pracujete.
  • /context – ukáže, čo práve zaberá miesto v kontextovom okne.

Prečo Claude Code míňa limit tak rýchlo

  • S každou požiadavkou sa posiela celá konverzácia – a každé volanie nástroja (načítanie súboru, spustenie testov) je ďalšia požiadavka s týmto kontextom. Jednoriadková otázka v relácii, ktorá je otvorená celý deň, stojí stále celú históriu.
  • Návrat po prestávke – vaša prvá správa po vypršaní vyrovnávacej pamäte (prompt cache) znova spracuje celý kontext.
  • Subagenti a tímy agentov – každý posiela popri vašej hlavnej relácii vlastné požiadavky.
  • Práca na pozadí – naplánované úlohy a slučky bežia ďalej, aj keď ste preč.
  • Veľký CLAUDE.md a veľa serverov MCP – načítavajú sa do kontextu pri každej relácii.
  • Najväčší model a vysoké úsilie – tokeny premýšľania sa počítajú ako výstup.

Ako limit predĺžiť

  1. /clear medzi nesúvisiacimi úlohami. Starý kontext sa posiela s každou správou. Ak sa chcete k relácii neskôr vrátiť cez /resume, najprv ju pomenujte cez /rename.
  2. /compact pri dlhých úlohách, v ktorých chcete pokračovať – zhrnie konverzáciu (aj to je veľká požiadavka, preto ho nespúšťajte každých pár minút).
  3. Model zvoľte podľa úlohy cez /model a pri jednoduchej práci znížte /effort.
  4. Odľahčite svoje nastavenie: CLAUDE.md držte krátky (špecializované pokyny presuňte do skills) a servery MCP, ktoré nepoužívate, vypnite cez /mcp.
  5. Píšte konkrétne zadania – „pridaj validáciu vstupu do prihlasovacej funkcie v auth.ts“ namiesto „vylepši tento kód“.
  6. Pri väčších zmenách použite plánovací režim (Shift+Tab) a stlačte Esc včas, keď sa Claude vyberie zlým smerom.
  7. Zatvorte relácie a zastavte slučky, ktoré už nepotrebujete.

Keď v Claude Code narazíte na limit

  • Claude Code vám povie, či ste narazili na limit relácie alebo na týždenný limit a kedy sa obnoví. Prepnutie modelu pri nich nepomôže – platia pre všetky modely spolu (pomôže len pri týždennom limite konkrétneho modelu).
  • Ak sa 5-hodinový limit dosiahne uprostred odpovede, Claude Code ju môže dokončiť s malou, obmedzenou rezervou („wrapping up“).
  • So zapnutými kreditmi na používanie (/usage-credits) môžete pracovať ďalej a za využitie navyše zaplatiť, až do mesačného stropu, ktorý si nastavíte.
  • Inak počkajte na obnovenie limitu – Claude Code vie aj počkať a prerušenú úlohu potom automaticky dokončiť.

Pozrite si limit skôr, než spustíte veľkú úlohu

Usage Meter for Claude je bezplatné rozšírenie prehliadača, ktoré ukazuje vašu spotrebu v Claude na ikone v paneli nástrojov – vrátane spotreby z Claude Code. Vyskakovacie okno ukazuje limit relácie aj týždenný limit s časom obnovenia a predpoveďou, kedy ho pri súčasnom tempe miniete, a skôr než na limit narazíte, dostanete upozornenie. Ideálne, keď sa rozhodujete, či ten refaktoring spustiť hneď, alebo až po obnovení limitu.

Časté otázky

Má Claude Code vlastný limit používania?

Nie. S predplatným Pro, Max alebo Ultra má Claude Code ten istý 5-hodinový limit relácie aj týždenný limit ako claude.ai a Claude Desktop.

Ako zistím svoju spotrebu v Claude Code?

Spustite /usage. Ukáže spotrebu vášho plánu a to, čo ju míňa. Spotrebu zo všetkých vašich zariadení nájdete na claude.ai v Settings → Usage.

Prečo Claude Code míňa môj limit tak rýchlo?

Každá požiadavka nesie celú konverzáciu aj výsledky nástrojov a subagenti, servery MCP a dlhé relácie pridávajú ďalšie. Najviac pomáha vyčistiť kontext medzi úlohami a používať ľahšie modely.

Pomôže po dosiahnutí limitu prepnúť na iný model?

Pri limite relácie ani pri týždennom limite nie – tie platia pre všetky modely spolu. Pomôže to len vtedy, keď ste narazili na týždenný limit konkrétneho modelu.

Môžem po dosiahnutí limitu pracovať ďalej?

Áno, ak máte pri platenom pláne zapnuté kredity na používanie – za využitie navyše platíte až do mesačného stropu, ktorý si nastavíte. Inak počkáte na obnovenie limitu.
