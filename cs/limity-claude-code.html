Limity Claude Code v kostce: co se započítává, jak je zkontrolovat a jak ušetřit

Aktualizováno 20. listopadu 2026 · čtení na 6 minut

EnglishSlovenčinaČeštinaDeutschItalianoFrançais
Stručně: s tarifem Pro, Max nebo Ultra nemá Claude Code žádnou samostatnou kvótu – čerpá ze stejného 5hodinového limitu relace i týdenního limitu jako claude.ai a Claude Desktop. Příkazem /usage v Claude Code zjistíte spotřebu svého tarifu a to, co ji čerpá. Nejrychleji limit vyčerpají dlouhé relace, velký kontext, subagenti a servery MCP; nejvíc ušetříte pomocí /clear, lehčího modelu a konkrétních zadání.

Claude Code sdílí limity vašeho tarifu

Když se do Claude Code přihlásíte svým předplatným claude.ai, veškerá aktivita v Claude Code, v chatu na claude.ai, v Claude Desktop i v rozšířeních pro IDE (VS Code, JetBrains) se započítává do jedné společné sady limitů:

TarifLimity, které platí pro Claude Code
Pro5hodinový limit relace + týdenní limit
Max5× Pro, každých 5 hodin i každý týden; navíc samostatný týdenní limit pro největší model
Ultra10× Pro každý týden; ověřené účty nemají 5hodinový limit; samostatný týdenní limit pro největší model

Dopoledne intenzivního programování vám tak odpoledne na chatování nemusí moc nechat – a naopak. Úplné srovnání tarifů najdete v článku Claude Pro vs Max vs Ultra.

Pozor na klíče API: pokud je nastavená proměnná prostředí ANTHROPIC_API_KEY, Claude Code místo vašeho předplatného použije tento klíč – a za každý požadavek platíte ceny API.

Jak zkontrolovat spotřebu v Claude Code

  • /usage – zobrazí ukazatele spotřeby vašeho tarifu a rozpis toho, co je čerpá: skilly, subagenti, pluginy i jednotlivé servery MCP, s doporučeními, například zkrátit velký CLAUDE.md. Klávesami d / w přepínáte mezi posledními 24 hodinami a 7 dny.
  • Settings → Usage (Nastavení → Využití) na claude.ai – směrodatný přehled limitu relace i týdenního limitu včetně spotřeby z jiných počítačů, z chatu a z telefonu. Rozpis v /usage vychází jen z místní historie relací na počítači, u kterého právě sedíte.
  • /context – ukáže, co právě zabírá místo v kontextovém okně.

Proč Claude Code čerpá limit tak rychle

  • S každým požadavkem se posílá celá konverzace – a každé volání nástroje (čtení souboru, spuštění testů) je další požadavek, který tento kontext nese. Jednořádková otázka v relaci otevřené celý den pořád stojí celou historii.
  • Návrat po pauze – vaše první zpráva po vypršení mezipaměti promptů znovu zpracuje celý kontext.
  • Subagenti a týmy agentů – každý z nich posílá vlastní požadavky navíc k vaší hlavní relaci.
  • Práce na pozadí – naplánované úlohy a smyčky běží dál, i když nejste u počítače.
  • Velký CLAUDE.md a mnoho serverů MCP – načítají se do kontextu v každé relaci.
  • Největší model a vysoké úsilí – tokeny přemýšlení se počítají jako výstup.

Jak s limitem vydržet déle

  1. /clear mezi nesouvisejícími úkoly. Zastaralý kontext se posílá znovu s každou zprávou. Pokud se chcete k relaci později vrátit přes /resume, pojmenujte ji nejdřív pomocí /rename.
  2. /compact u dlouhých úkolů, ve kterých chcete pokračovat – shrne konverzaci (sám o sobě je to velký požadavek, takže ho nespouštějte každých pár minut).
  3. Zvolte model podle úkolu pomocí /model a u jednoduché práce snižte /effort.
  4. Zeštíhlete své nastavení: udržujte CLAUDE.md stručný (specializované pokyny přesuňte do skillů) a servery MCP, které nepoužíváte, vypněte přes /mcp.
  5. Pište konkrétní zadání – „přidej validaci vstupu do přihlašovací funkce v auth.ts“ místo „vylepši tenhle kód“.
  6. Používejte režim plánování (Shift+Tab) u větších změn a stiskněte včas Esc, když se Claude vydá špatným směrem.
  7. Zavírejte relace a zastavujte smyčky, které už nepotřebujete.

Další příčiny a řešení – i pro chat na claude.ai – najdete v článku Proč se limit v Claude vyčerpá tak rychle?

Když v Claude Code narazíte na limit

  • Claude Code vám řekne, jestli jste narazili na limit relace, nebo na týdenní limit, a kdy se obnoví. Přepnutí na jiný model u nich nepomůže – platí pro všechny modely společně (pomůže jen u týdenního limitu konkrétního modelu).
  • Pokud 5hodinový limit dojde uprostřed odpovědi, může ji Claude Code dokončit z malé, omezené rezervy („wrapping up“).
  • Se zapnutými kredity za využití (/usage-credits) můžete pracovat dál a spotřebu navíc zaplatit až do měsíčního stropu, který si sami nastavíte.
  • Jinak počkejte na obnovení limitu – Claude Code umí také počkat a přerušenou úlohu pak automaticky dokončit.

Mějte limit na očích dřív, než začnete velký úkol

Usage Meter for Claude je bezplatné rozšíření prohlížeče, které vám ukazuje spotřebu Claude přímo na ikoně v panelu nástrojů – včetně spotřeby z Claude Code. Vyskakovací okno zobrazuje limit relace i týdenní limit s časy obnovení a předpověď, kdy limit při současném tempu vyčerpáte, a ještě než na limit narazíte, dostanete oznámení. Ideální, když se rozhodujete, jestli refaktoring spustit hned, nebo až po obnovení limitu.

Časté dotazy

Má Claude Code vlastní limit?

Ne. S předplatným Pro, Max nebo Ultra sdílí Claude Code stejný 5hodinový limit relace i týdenní limit jako claude.ai a Claude Desktop.

Jak zjistím svou spotřebu v Claude Code?

Spusťte /usage. Ukáže spotřebu vašeho tarifu a to, co ji čerpá. Spotřebu ze všech vašich zařízení najdete na claude.ai v Settings → Usage.

Proč Claude Code vyčerpá můj limit tak rychle?

Každý požadavek nese celou konverzaci včetně výsledků nástrojů a subagenti, servery MCP a dlouhé relace přidávají další. Nejvíc pomůže vyčistit kontext mezi úkoly a používat lehčí modely.

Pomůže přepnout na jiný model, když narazím na limit?

U limitu relace ani u týdenního limitu ne – ty platí pro všechny modely společně. Pomůže jen tehdy, když narazíte na týdenní limit konkrétního modelu.

Můžu po dosažení limitu pracovat dál?

Ano, pokud máte u placeného tarifu zapnuté kredity za využití – spotřebu navíc zaplatíte až do měsíčního stropu, který si sami nastavíte. Jinak počkáte na obnovení limitu.
