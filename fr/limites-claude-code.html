Les limites d'utilisation de Claude Code expliquées : ce qui compte, comment les vérifier et comment économiser

Mis à jour le 20 novembre 2026 · 6 min de lecture

En bref : avec une offre Pro, Max ou Ultra, Claude Code n'a pas de quota séparé – il utilise les mêmes limites de session de 5 heures et hebdomadaires que claude.ai et Claude Desktop. Lancez /usage dans Claude Code pour voir la consommation de votre forfait et ce qui l'utilise. Les longues sessions, un contexte volumineux, les sous-agents et les serveurs MCP épuisent la limite le plus vite ; /clear, un modèle plus léger et des prompts précis permettent d'économiser le plus.

Claude Code partage les limites de votre offre

Lorsque vous vous connectez à Claude Code avec votre abonnement claude.ai, toute l'activité dans Claude Code, le chat claude.ai, Claude Desktop et les extensions pour IDE (VS Code, JetBrains) est décomptée d'un seul ensemble de limites partagé :

OffreLimites qui s'appliquent à Claude Code
ProLimite de session de 5 heures + limite hebdomadaire
Max5× Pro, toutes les 5 heures et chaque semaine ; plus une limite hebdomadaire distincte pour le plus gros modèle
Ultra10× Pro chaque semaine ; les comptes vérifiés n'ont pas de limite de 5 heures ; limite hebdomadaire distincte pour le plus gros modèle

Une matinée de code intensif peut donc ne laisser que peu de marge pour discuter l'après-midi – et inversement. Pour une comparaison complète des offres, consultez Claude Pro, Max ou Ultra : le comparatif.

Attention aux clés API : si la variable d'environnement ANTHROPIC_API_KEY est définie, Claude Code utilise cette clé au lieu de votre abonnement – et vous payez chaque requête au tarif de l'API.

Comment vérifier votre consommation dans Claude Code

  • /usage – affiche les barres de consommation de votre forfait et le détail de ce qui les utilise : skills, sous-agents, plugins et chaque serveur MCP, avec des recommandations comme alléger un CLAUDE.md trop volumineux. Appuyez sur d / w pour basculer entre les dernières 24 heures et les 7 derniers jours.
  • Settings → Usage (Paramètres → Utilisation) sur claude.ai – la vue de référence de vos limites de session et hebdomadaires, y compris la consommation depuis d'autres ordinateurs, le chat et votre téléphone. Le détail de /usage ne s'appuie que sur l'historique de sessions local de la machine que vous utilisez.
  • /context – montre ce qui occupe actuellement de la place dans la fenêtre de contexte.

Pourquoi Claude Code épuise si vite votre limite

  • Toute la conversation est envoyée avec chaque requête – et chaque appel d'outil (lire un fichier, lancer des tests) est une requête de plus qui transporte ce contexte. Une question d'une ligne dans une session ouverte toute la journée coûte quand même tout l'historique.
  • Le retour après une pause – votre premier message après l'expiration du cache de prompts retraite tout le contexte.
  • Les sous-agents et les équipes d'agents – chacun envoie ses propres requêtes en plus de votre session principale.
  • Le travail en arrière-plan – les tâches planifiées et les boucles continuent de tourner pendant votre absence.
  • Un CLAUDE.md volumineux et de nombreux serveurs MCP – chargés dans le contexte à chaque session.
  • Le plus gros modèle et un effort élevé – les tokens de réflexion comptent comme des tokens de sortie.

Comment faire durer votre limite plus longtemps

  1. /clear entre deux tâches sans rapport. Le contexte obsolète est renvoyé avec chaque message. Utilisez d'abord /rename si vous voulez reprendre la session plus tard avec /resume.
  2. /compact pour les longues tâches que vous voulez poursuivre – la commande résume la conversation (c'est elle-même une requête volumineuse, ne la lancez donc pas toutes les deux minutes).
  3. Choisissez le modèle adapté à la tâche avec /model, et baissez /effort pour le travail simple.
  4. Allégez votre configuration : gardez CLAUDE.md court (déplacez les instructions spécialisées dans des skills) et désactivez avec /mcp les serveurs MCP que vous n'utilisez pas.
  5. Rédigez des prompts précis – « ajoute une validation des entrées à la fonction de connexion dans auth.ts » plutôt que « améliore cette base de code ».
  6. Utilisez le mode plan (Shift+Tab) pour les changements importants et appuyez tôt sur Esc si Claude part dans la mauvaise direction.
  7. Fermez les sessions et arrêtez les boucles dont vous n'avez plus besoin.

Quand vous atteignez la limite dans Claude Code

  • Claude Code vous indique si vous avez atteint la limite de session ou la limite hebdomadaire, et quand elle se réinitialise. Changer de modèle n'aide pas pour ces limites – elles s'appliquent à tous les modèles (cela n'aide que pour une limite hebdomadaire propre à un modèle).
  • Si la limite de 5 heures est atteinte au milieu d'une réponse, Claude Code peut la terminer avec une petite marge plafonnée (« wrapping up »).
  • Avec les crédits d'utilisation activés (/usage-credits), vous pouvez continuer à travailler et payer l'utilisation supplémentaire, jusqu'à un plafond mensuel que vous fixez.
  • Sinon, attendez la réinitialisation – Claude Code peut aussi attendre et reprendre automatiquement la tâche interrompue.

Voyez votre limite avant de lancer une grosse tâche

Usage Meter for Claude est une extension de navigateur gratuite qui affiche votre consommation Claude sur l'icône de la barre d'outils – y compris l'utilisation depuis Claude Code. La fenêtre contextuelle montre vos limites de session et hebdomadaires avec leurs heures de réinitialisation et une prévision du moment où vous serez à court à votre rythme actuel, et une notification vous avertit avant que vous n'atteigniez la limite. Idéal pour décider de lancer ce refactoring maintenant ou après la réinitialisation.

Questions fréquentes

Claude Code a-t-il sa propre limite d'utilisation ?

Non. Avec un abonnement Pro, Max ou Ultra, Claude Code partage les mêmes limites de session de 5 heures et hebdomadaires que claude.ai et Claude Desktop.

Comment vérifier ma consommation dans Claude Code ?

Lancez /usage. La commande affiche la consommation de votre forfait et ce qui l'utilise. Pour la consommation sur tous vos appareils, consultez Settings → Usage sur claude.ai.

Pourquoi Claude Code épuise-t-il ma limite si vite ?

Chaque requête transporte toute la conversation ainsi que les résultats des outils, et les sous-agents, les serveurs MCP et les longues sessions en ajoutent encore. Vider le contexte entre deux tâches et utiliser des modèles plus légers est ce qui aide le plus.

Changer de modèle aide-t-il quand j'atteins la limite ?

Pas pour la limite de session ni pour la limite hebdomadaire, qui s'appliquent à tous les modèles. Cela n'aide que si vous atteignez une limite hebdomadaire propre à un modèle.

Puis-je continuer à travailler après avoir atteint la limite ?

Oui, si les crédits d'utilisation sont activés sur votre offre payante – vous payez l'utilisation supplémentaire jusqu'à un plafond mensuel que vous fixez. Sinon, vous attendez la réinitialisation.
