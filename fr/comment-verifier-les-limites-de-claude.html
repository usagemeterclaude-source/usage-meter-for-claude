Comment vérifier vos limites d'utilisation de Claude (session, hebdomadaire et Claude Code)

Mis à jour le 17 novembre 2026 · 5 min de lecture

EnglishSlovenčinaČeštinaDeutschItalianoFrançais
En bref : sur claude.ai, ouvrez Settings → Usage (Paramètres → Utilisation). Vous y verrez votre limite de session de 5 heures et vos limites hebdomadaires sous forme de barres de progression, chacune avec l'heure de sa prochaine réinitialisation. Dans Claude Code, lancez /usage. claude.ai, Claude Code et Claude Desktop comptent tous dans les mêmes limites.

1. Vérifier vos limites sur claude.ai

  1. Ouvrez claude.ai et connectez-vous.
  2. Cliquez sur votre nom ou vos initiales en bas à gauche, puis choisissez Settings.
  3. Ouvrez l'onglet Usage.

La page Usage est disponible avec les offres Pro, Max, Ultra, Team et Enterprise avec licences par utilisateur. Elle affiche :

Ce que vous voyezCe que cela signifie
Session en coursLa part de votre limite de session de 5 heures déjà utilisée et l'heure de sa réinitialisation.
Hebdomadaire – tous les modèlesVotre limite hebdomadaire pour l'ensemble des modèles et l'heure de sa réinitialisation.
Hebdomadaire – un modèle spécifiqueSur certaines offres, il existe une limite hebdomadaire distincte pour le plus gros modèle.
Crédits d'utilisationS'ils sont activés, le montant dépensé au-delà de votre offre et votre plafond mensuel.

2. Vérifier vos limites dans Claude Code

Si vous utilisez Claude Code avec votre abonnement claude.ai, tapez /usage dans une session. La commande affiche une répartition de l'utilisation de votre forfait, avec des suggestions pour l'utiliser plus efficacement.

Gardez à l'esprit que /usage s'appuie sur l'historique de vos sessions locales – l'utilisation depuis d'autres ordinateurs, depuis claude.ai ou depuis votre téléphone n'y figure pas. Pour une vue d'ensemble complète, utilisez Settings → Usage sur claude.ai. Les crédits d'utilisation se gèrent dans Claude Code avec /usage-credits.

3. Le fonctionnement des limites Claude

La limite de session de 5 heures

Sur les offres payantes, une session commence avec votre premier message et se réinitialise entièrement cinq heures plus tard. Si vous commencez à travailler à 9 h 00, votre session se réinitialise à 14 h 00 – quelle que soit votre utilisation entre-temps.

Les limites hebdomadaires

Les limites hebdomadaires se réinitialisent chaque semaine à une heure fixe attribuée à votre compte – et non le lundi pour tout le monde. Le jour et l'heure exacts sont indiqués dans Settings → Usage.

Un quota partagé

Discuter sur claude.ai, coder avec Claude Code et utiliser Claude Desktop : tout puise dans les mêmes limites. Une longue session Claude Code le matin peut laisser moins de marge pour discuter l'après-midi. Anthropic peut aussi ajuster les limites au fil du temps pour gérer la capacité, si bien que la quantité exacte de travail qui tient dans une session peut varier.

4. Que faire quand vous atteignez la limite

  • Attendez la réinitialisation. Settings → Usage vous indique précisément quand votre session ou votre semaine se réinitialise.
  • Utilisez les crédits d'utilisation. Sur les offres payantes où les crédits d'utilisation sont activés, vous pouvez continuer à travailler et payer l'utilisation supplémentaire.
  • Ouvrez une nouvelle conversation pour chaque nouveau sujet. Les longues conversations consomment davantage votre limite à chaque message, car Claude relit tout le contexte.
  • Utilisez un modèle plus léger pour les tâches simples et réservez le plus gros aux tâches difficiles.
  • Planifiez les tâches lourdes – vérifiez ce qu'il reste de votre session avant de lancer une grosse tâche Claude Code.

Voyez vos limites sans ouvrir les paramètres

Usage Meter for Claude est une extension de navigateur gratuite qui garde votre utilisation de Claude sous les yeux : le pourcentage s'affiche sur l'icône de la barre d'outils, la fenêtre contextuelle montre vos limites de session et hebdomadaires avec leurs heures de réinitialisation, une prévision vous indique quand vous serez à court à votre rythme actuel, et une notification vous avertit avant que vous n'atteigniez la limite. L'utilisation depuis Claude Code, l'application de bureau et votre téléphone est incluse.

Questions fréquentes

Où puis-je voir mes limites d'utilisation de Claude ?

Sur claude.ai, dans Settings → Usage, disponible avec les offres Pro, Max, Ultra, Team et Enterprise avec licences par utilisateur.

Quand la limite de session de 5 heures se réinitialise-t-elle ?

Cinq heures après le premier message de la session.

Quand les limites hebdomadaires se réinitialisent-elles ?

Chaque semaine à une heure fixe attribuée à votre compte – consultez Settings → Usage pour connaître la vôtre.

Claude Code a-t-il des limites distinctes ?

Non. Claude Code, claude.ai et Claude Desktop partagent les mêmes limites. Dans Claude Code, /usage n'affiche que l'utilisation de vos sessions locales.

Puis-je voir mon utilisation avec l'offre gratuite ?

L'offre gratuite a aussi des limites, mais la page Usage avec les barres de session et hebdomadaires est réservée aux offres payantes.
